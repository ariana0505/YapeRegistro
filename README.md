# Registro de pagos del minimarket Celia

Celia administra un minimarket y recibe pagos por Yape. Hoy apunta en un cuaderno el nombre del cliente, el monto y la fecha. Después busca cada anotación y la compara manualmente con los movimientos de Yape. Esto le toma tiempo, puede causar confusiones y dificulta consultar pagos antiguos o sumar un día.

El producto busca que Celia registre 20 pagos, encuentre cualquiera por nombre o fecha en menos de 30 segundos y vea el total diario sin hacer la suma a mano.

## Estado inicial

Este primer commit deja definida la idea y prepara el repositorio. Todavía no contiene un programa ejecutable; la aplicación se añadirá en commits posteriores. La verificación de los pagos seguirá siendo manual en Yape.
